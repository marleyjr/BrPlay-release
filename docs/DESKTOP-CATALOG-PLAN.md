# Desktop catalog adaptation

## Scope

- Android/TV: preserve the existing catalog and Media3 player through a platform wrapper.
- Desktop: reuse the same catalog UI and bounded API queries, native TDLib/mpv player, mouse/keyboard navigation and resizable layouts. Preserve Telegram login and app lock.
- Web: unchanged. JVM networking and native players cannot be used in the browser.

## Edge cases and checks

Handle missing configuration, offline/error retry, empty pages, missing metadata, cancellation and logout, duplicate delivery retries, keyboard Back and returning from the player. Keep twenty-title pages and bounded bot-history reads. No new video download/export action. Source edits need less than 1 MB; local free space is checked before editing. Native playback and visual validation still need a Windows device.
